# Community Conduct / 社区行为准则

We welcome users and contributors of different backgrounds and experience levels. Discuss the software and evidence, not personal attributes. Be respectful when reporting bugs, reviewing code and disagreeing.

欢迎不同背景和经验的使用者、贡献者参与。请围绕软件、复现和证据讨论，尊重不同意见，不攻击个人。

## Expectations / 基本要求

- Be constructive, patient and clear. Chinese and English contributions are welcome.
- Do not harass, threaten, discriminate, impersonate others or publish anyone's private information.
- Do not post spam, misleading affiliations, private chats, credentials or material you have no right to distribute.
- Respect software licenses and artwork permissions. A repository's code license does not automatically license third-party character art.
- Use issues for reproducible problems and proposals. Use private security reporting for vulnerabilities.

请友善、耐心、清楚地沟通，欢迎中英文参与。禁止骚扰、威胁、歧视、冒充、泄露隐私、垃圾信息和误导性官方关联声明。请尊重软件与美术素材各自的许可，不发布无权分发的内容；安全问题走私密报告渠道。

## Moderation / 维护方式

Maintainers may ask for changes, edit or remove harmful content, lock discussions, or restrict participation in response to violations. They should apply these rules consistently and avoid sharing sensitive report details publicly.

维护者可要求修改、移除不当内容、锁定讨论或限制参与，并应一致执行规则，避免公开敏感举报信息。

For ordinary conduct concerns, flag the relevant content to maintainers without reposting private information. For abuse or threats requiring a private platform report, use GitHub's **Report abuse** controls. There is currently no separate private conduct mailbox or guaranteed moderation response time.

一般社区问题可在不重复传播隐私的前提下提醒维护者；需要平台私密处理的滥用、威胁，请使用 GitHub 的 **Report abuse**。项目目前没有单独的私人举报邮箱，也不承诺固定处理时间。

These expectations complement the [GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).
