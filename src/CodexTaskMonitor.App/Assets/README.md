# UI artwork

`TaskPaperWorker.png` is original AI-generated black-marker artwork created for the floating task tray. It shows one primitive worker carrying a blank task sheet. The design was informed by the visual guidelines in Hchen1218/heytea-style; no private reference-study cutouts, official logos or brand mascots were copied.

It is embedded as a WPF resource in the task-center/tray headings and empty states. It does not require network requests or a runtime image cache. Interface labels and task content remain native text.

The terminal-robot sheets are generated by this repository's drawing/theme scripts. The project icon, those original sheets and this task-paper illustration are included under the root MIT license. External downloaded character artwork is not included or relicensed here.
