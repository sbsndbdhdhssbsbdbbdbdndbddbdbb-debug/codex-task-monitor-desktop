# Codex Task Monitor

Windows WPF companion for people running several Codex tasks in the background. Keep exactly three categories: in progress, needs attention, recently completed. Preserve tray access, multi-monitor dragging, compact mode, do not disturb and project-local pet storage. Preview images must not create a persistent disk cache.

The user requests a comprehensive UI refinement and smoother download-to-use workflow. Visual reference: HEYTEA-inspired crisp black and white, confident Chinese typography, practical spacing, colorful character assets and restrained motion. No HEYTEA logos or artwork. Target: resizable native Windows desktop.
